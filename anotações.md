Ao inciar e instalar o pacote do projeto, vc pode usar o c# project details e selcionar GameStore.API com icone de globo, com botao direito do mouse, seleciona a opção build
Ou Direciona o direitorio no gameSToreAPI no terminal e coloca dotnet build
Ou ctrl shift B

Para rodar a aplicação F5 e seleciona começar com https ou http
Ou no seu terminal coloca dotnet watch
Isso rodara a aplicação em debug mode
Pra rodar sem debug, vc pode slecionar na seção de C# a pasta api com globo e colocar debug - rodar sem debug

"launchBrowser": false, previne que o app abra uma nova aba toda vez que rodar a aplicação
